# phalanx-pilot-web

A tiny ESM Node package of small string and array helpers. It has no
dependencies and uses the built-in `node:test` runner. Requires Node.js 20+.

This repository is a **Phalanx acceptance target**. It exists so
[Phalanx](https://github.com/caltseng/phalanx) end-to-end musters have a small,
real repository with CI, a protected default branch, and open issues to work on.

## Test

```sh
npm test
```
